# Nikhil Sharma — Portfolio

A responsive personal portfolio built with Vite, React, TypeScript, and the existing Lucide icon set.

## Local development

```sh
npm ci
npm run dev
```

## Quality checks

```sh
npm run lint
npm run typecheck
npm test
npm run build
```

## Project notes

- Interface studies in the selected-project cards are illustrative compositions, not product screenshots or sample account data.
- Public links are included only where a repository or project site can be verified. Projects without a verified public destination are presented without a fabricated link.
- The CV download is intentionally omitted until a valid PDF is available.
- The Vercel project is configured for the existing production domain; pushes to `main` are expected to trigger its connected deployment.
